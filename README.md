# Моя коллекция

**Моя коллекция** — учебный веб-проект на Django, созданный для личной каталогизации фильмов и книг. Проект позволяет создавать карточки, присваивать им жанры, просматривать список своей коллекции, редактировать и удалять записи.

Проект выполнен в рамках лабораторной работы по дисциплине, связанной с разработкой веб-приложений на Python.

---

## Функциональность

- Регистрация и авторизация пользователей  
- Создание, редактирование и удаление карточек предметов  
- Присвоение жанров карточкам с возможностью выбора из существующих или добавления новых  
- Просмотр списка своей коллекции  
- Управление профилем: смена email и пароля  
- Разделение данных по пользователям  

---

## Используемые технологии

- Python 3  
- Django 6  
- SQLite  
- HTML / CSS (шаблоны Django)  

---

## Структура проекта

- library_project/ — основной Django-проект
- library/ — приложение Library
- app/ — Django-приложение для работы с коллекцией
- templates/ — HTML-шаблоны
- migrations/ — миграции базы данных
- manage.py — файл управления Django-проектом

## Установка и запуск проекта

### Клонирование репозитория

git clone https://github.com/Anastasiien/python.git
cd library_project/library

### Создание и активация виртуального окружения:

### Windows
python -m venv venv
venv\Scripts\activate

### Linux / macOS
python3 -m venv venv
source venv/bin/activate

### Установка зависимостей:

pip install -r requirements.txt

### Применение миграций:

python manage.py migrate

### Создание суперпользователя для доступа в админку (по желанию):

python manage.py createsuperuser

### Запуск сервера разработки:

python manage.py runserver


## После запуска приложение будет доступно по адресу:
http://127.0.0.1:8000/

## Для управления коллекцией перейдите по адресу:
http://127.0.0.1:8000/collection/

## Для входа в админку:
http://127.0.0.1:8000/admin/
